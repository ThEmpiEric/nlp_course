# Procesamiento de Lenguaje Natural (NLP)

Este repositorio contiene mis soluciones propuestas para la materia de NLP impartida en CIMAT Guanajuato.

## Contenido
- **T1**: Minería de las versiones estenográficas de AMLO y Claudia Sheinbaum, además del uso de herramientas para PNL como **NLTK**.
- **T2**: BoW y BoE para los tweets de la base MEX-A3T: Fake News and Aggressiveness Analysis.
- **T3**: TCOR, Random Indexing and words visualization.
- **T4**: Implementación de un modelo probabilístico de lenguaje.  
- **T5**: Práctica en la que se implementa el modelo neuronal de Bengio en PyTorch, así como versiones del modelo a nivel de carácter y palabra.  
- **T6**: Modelo neuronal de atención en jerarquía para *author profiling*. Modelo GRU con mecanismo de atención.  
- **Tiny Projects**: Proyecto que realiza un análisis utilizando técnicas de NLP sobre reseñas de sitios emblemáticos de la ciudad de Guanajuato capital. Modelo BERT a nivel de tweet y se emplea voto mayoritario para inferir la etiqueta final en la tarea de *author profiling*.  
- **Project**: Implementación de una herramienta de búsqueda semántica, utiliza los títulos y las transcripciones para generar embeddings contextualizados.
